# SHAP explanation for XGBoost p85 models

## Objective

Explain the saved direct XGBoost p85 models with SHAP. Report global feature
importance, feature direction, local examples, and attribution checks.

## Decisions

- Use `shap.TreeExplainer` for the saved XGBoost tree boosters.
- Explain raw p85 fantasy-point output.
- Use tree-path-dependent perturbation without a separate background matrix.
- Explain all 2024 and 2025 held-out rows for all four positions.
- Limit plots to a deterministic sample of at most 1,500 rows per model.
- Treat SHAP direction as model association, not causation.

## Implementation

- Added `backtest_fbg_2023_2025/scripts/09_explain_xgb_p85_shap.py`.
- Added SHAP and matplotlib to `scripts/requirements-xgb.txt`.
- Documented the command and output path in `backtest_fbg_2023_2025/README.md`.
- Wrote outputs under
  `backtest_fbg_2023_2025/outputs/xgb_p85_projection/shap/`.

## Results

The direct model uses projection data as a real driver for RB, TE, and WR.

- RB 2025: `consensus_projected_score` has mean absolute SHAP 4.398 points.
- TE 2025: `rec-tgt` has mean absolute SHAP 2.046 points.
- WR 2025: `rec-yds` has mean absolute SHAP 2.006 points.
- QB 2025: `consensus_projected_score` has mean absolute SHAP 0.902 points.

QB also assigns large attribution to `pass-sck` and `n_projectors`. The
`n_projectors` feature is nearly binary in the target data. The positive effect
of projected sacks is counterintuitive. These features need stability checks
before any QB production use.

`consensus_projected_score` and `projection_fpts` are exact duplicate inputs.
Their SHAP importance must be interpreted as a combined pair. The individual
split is not meaningful and should be removed in a follow-up retrain.

The largest 2025 QB underprediction example was Trevor Lawrence. The actual
score was 44.30, while the model p85 was 24.57. The waterfall plot shows how
the model reached that estimate. This is an error explanation, not a causal
explanation of the game result.

## Verification

- SHAP ran for 8 models and 9,390 held-out rows.
- All model keys and feature names matched the saved experiment artifacts.
- Maximum SHAP additivity error was `0.00004578` fantasy points.
- Global bar plots, beeswarm plots, three dependence plots per model, and two
  waterfall plots per model were written.

## Field-guide review status

No permanent field-guide rule was added. The QB feature warning is specific to
this experiment until later seasons or a stability study support a durable
rule.
